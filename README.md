# Byte-by-Byte - 我的学习记录

这个仓库记录了我学习 C/C++ 过程中各个技术栈的内容，每个**分支**包含不同的技术栈和实践。

## 分支结构

- **main**: README 用于引导。

- **data-structure-c**: 学习数据结构（链表、树、图等）相关的 C 代码。

  > 这部分代码主要是基于LHQ的顺序进行学习

- **vulkan-triangle**: vulkan实例（最简三角形）。

## 项目目标

该仓库的目标是记录我学习 C 语言过程中所涉及的不同技术栈、算法、数据结构等，并帮助自己回顾和总结所学知识。

## 使用说明

每个分支都有一个特定的学习目标和内容，你可以根据需要切换到对应的分支查看相应的代码和资料。
